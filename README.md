# bear-sky-map

熊出没が報告されていない、夜空が暗い（SQM 20以上）「天体観測エリア」を地図上で探すWebアプリ。

- **frontend/** 地図UI (Vite + TypeScript + MapLibre GL JS)
- **backend/** データ取得・ジオコーディング・空間演算 (Python)
- **data/** raw=取得した生データ / processed=加工済みGeoJSON

## 起動

```powershell
.\start-app.ps1          # dev server を起動してブラウザを開く
```

## データ更新

```powershell
.\run_refresh.ps1        # 最新データの取得 → 再計算 → フロントへ反映 → Discord通知
```

内部では `backend/refresh_data.py` が以下を順に実行する。

1. **取得**
   - 宮城県: 公開ページから最新Excelのリンクを**動的に解決**してダウンロード
     （ファイル名に更新日が入るため固定URLは使えない）。中身がxlsxであることを検証する。
   - 東京都: 配布CSVが2026-06-10で更新停止しているため、公開ダッシュボード
     「TOKYOくまっぷ」の一覧表をPlaywrightで取得する（`scrape_tokyo_dashboard.py`）。
     既定では**記載日の降順**で上から読み、既知の記録が続いたら打ち切る増分取得
     （全件 約75秒 → 増分 約20秒）。訂正の取りこぼしを防ぐため月1回は `--full-scrape` を回す。
2. **変換** どちらも住所テキストを国土地理院APIでジオコーディング。結果は
   `data/processed/geocode_cache.json` に永続キャッシュされ、次回以降は新規レコードのみ
   APIを叩く（初回 約8分 → 2回目以降 数秒）。
3. **空間演算** 暗空エリア（SQM≥20）から直近90日の熊出没2kmバッファを差し引いて
   「直近熊"低頻出"&星観測"暗さ"良好エリア」を算出。
4. **公開** `frontend/public/data/` へGeoJSONをコピー。
5. **通知** 実行結果とデータ品質の指摘をDiscordへ送信。

### データ品質の指摘について

提供元（自治体）のデータには未来日付や表記ゆれなどの誤りが混ざることがある。
本パイプラインはそれらを**黙って補正せず必ず報告する**方針。過去の実例:

- 宮城: 地区欄に市町村名が重複（「登米市登米市中田町浅水」）→ 自動除去するが報告する
- 宮城: 公表日より後の日付のレコード（8/13公表の資料に8/31付）→ 報告のみ

## Discord通知の設定（任意）

1. Discordで通知を受けたいサーバーのチャンネルを開く
2. チャンネル名の横の⚙️（チャンネルの編集）→ **連携サービス** → **ウェブフック** → **新しいウェブフック**
3. **ウェブフックURLをコピー**
4. そのURLを `backend/discord_webhook.txt` に貼り付けて保存（1行だけ）

未設定でもパイプラインは動作する（通知がスキップされるだけ）。

> ウェブフックURLは「それを知っている人は誰でもそのチャンネルに投稿できる」秘密情報。
> `.gitignore` で除外済みなので、GitHubに公開する際も漏れない。

## 主な設定値

`backend/config.py` に集約してある。

| 定数 | 既定値 | 意味 |
|---|---|---|
| `RISK_WINDOW_DAYS` | 90 | この期間内（この日数ちょうどを含む）の出没がリスクバッファの対象 |
| `AGE_TAGS` | 90日/1年/2年/3年 | 対象外になった出没に付けるグレーのタグ。境界は「より前」（厳密に超過） |
| `RETENTION_YEARS` | 3 | これより古い記録は破棄（90日〜3年はグレー表示で残す） |
| `BUFFER_METERS` | 2000 | 出没地点まわりの危険半径 |
| `SQM_THRESHOLD` | 20.0 | 暗空とみなす夜空の明るさ |
| `REGION_PREFECTURE` | 東京都/宮城県 | 暗空エリアを切り抜く県 |

暗空エリアは県境（本土部分）で切り抜いている。これをしないと解析範囲の矩形が
そのまま地図に出てしまい、さらに「海の上」が暗空＝安全として表示されてしまう。

## データ出典

- 東京都環境局「ツキノワグマ目撃等情報」
- 宮城県「クマ目撃情報」
- Light Pollution Atlas 2025 (David J. Lorenz) — VIIRS衛星データに基づく夜空の明るさ
- 地図: 国土地理院「地理院タイル（淡色地図）」
- 住所の座標変換: 国土地理院「地名検索API」
- 県境: 国土交通省「国土数値情報（行政区域データ）」を
  [smartnews-smri/japan-topography](https://github.com/smartnews-smri/japan-topography) 経由で取得し加工

本アプリは国土交通省の国土数値情報（行政区域データ）を加工して作成しているが、
内容について国土交通省が保証するものではない。

## 免責

「熊リスクが低い」は絶対的な安全を意味しない。出没情報は報告されたものに限られ、
報告のない場所に熊がいないことを保証しない。実際の観測時は各自で安全対策を行うこと。
